# Security policy

## Reporting a vulnerability

Report privately through GitHub: **Security → Report a vulnerability** on the
affected repository, or email speedsharma.ai@gmail.com.

You will get an acknowledgement within 3 working days and an assessment
within 10. Please give us a reasonable time to fix before disclosing.

## Supported versions

mfeflow is pre-1.0. Only the latest published version gets fixes.
