# mfeflow

**The React micro-frontend boilerplate that keeps going after day one.**

Module Federation 2.0 on Rsbuild, with features à la carte (typed API URLs,
Google Tag Manager with Consent Mode v2, OpenTelemetry, lint and tsconfig
presets, CI), a self-hosted registry with one-command rollback, and
guardrails that keep many teams on one React, one tag manager and one tracer.

> **Early, built in the open.** Nothing is released yet.

| Repo                                            | What                                         |
| ----------------------------------------------- | -------------------------------------------- |
| [mfeflow](https://github.com/mfeflow/mfeflow)   | packages, CLI, features and docs             |
| [starter](https://github.com/mfeflow/starter)   | a ready-to-use project, generated by the CLI |
| [examples](https://github.com/mfeflow/examples) | ecommerce, dashboard and multi-repo examples |

```bash
npm create mfeflow@latest my-platform   # coming soon
```
