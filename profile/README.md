# mfeflow

**The React micro-frontend boilerplate that keeps going after day one.**

A shell and remotes on Module Federation 2.0, built with Rsbuild or Vite. Add features when you need them: typed env and API URLs, Google Tag Manager with Consent Mode v2, OpenTelemetry, theming, i18n, Tailwind, Storybook and more. A self-hosted registry deploys and rolls back a remote by moving a pointer, with no rebuild. Checks in CI keep many teams on one React, one tag manager and one tracer.

```bash
npm create mfeflow@latest my-platform
```

Version 0.8.0 is on npm, with 21 packages and 26 features. It can also start a shell on its own, a repo of remotes for a shell another team owns, or a tooling repo with no apps.
